# Local App Icons (Optional)

This directory is **Git-ignored** and reserved for personal local assets.

By default, Metro Launcher uses clean open-source vector brand drawables for primary media services and dynamically retrieves official high-resolution application banners from the Android TV `PackageManager` (`app.systemIcon`) for all other installed applications.

If you have personal custom icon packs or extracted PNG assets, you can keep them here for reference or personal custom builds.
